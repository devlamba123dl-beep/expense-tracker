# Expense Tracker for Students

A menu-based Python program that helps students record daily expenses,
view them by category, set a monthly budget and get SAFE / WARNING /
OVER BUDGET alerts.

## Features
- Add, view and filter expenses
- Category-wise summary with percentages and text bar chart
- Monthly budget with 80% warning
- Data saved in expenses.csv

## How to run
python expense_tracker.py
